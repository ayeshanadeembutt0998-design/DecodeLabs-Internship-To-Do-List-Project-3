# 📝 To-Do List

A clean and interactive **To-Do List web application** built using **HTML5, CSS3, and JavaScript**.

This project was created as **Project 3 during my Frontend Development internship at DecodeLabs**, focusing on JavaScript interactivity and DOM manipulation.

---

## 🚀 Features

- ➕ Add new tasks dynamically
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 📊 Dynamic task statistics
  - **Total Tasks**
  - **Completed Tasks**
  - **Remaining Tasks**
- 🔍 Filter tasks
  - **All**
  - **Active**
  - **Completed**
- 🌙 **Dark Mode / ☀️ Light Mode**
- ⌨️ Add tasks using the **Enter** key
- 🚫 Prevents empty tasks from being added
- 📱 Fully responsive design
- 🎨 Remix Icons for interface icons

---

## 🛠️ Technologies Used

- **HTML5** — Structure and semantic elements
- **CSS3** — Styling, responsive design, and dark mode
- **JavaScript** — Interactivity and DOM manipulation
- **Remix Icon** — Interface icons
